# data/archive/

Deprecated or superseded datasets kept for the record. Nothing here may be used by the app or by new code. Never delete.

- `health_facilities_gemini_audited/`: Gemini-audited health copy (byte-identical to `../health_facilities_audited.csv` in the parent folder). Replaced by `data/reference/health/health_facilities.csv`.
- `maritime_terminals_gemini_audited/`: 48 terminal rows audited by Gemini (copy of `../maritime_terminals_audited.csv`). Provenance beyond the file's own columns is UNKNOWN.
- `harbour_jetty_reference/`: README only. The jetty/harbour files are deprecated but stay in `data/reference/harbours/` and `data/manual/harbours/` because `scripts/build_vessel_services.py` still reads them.
